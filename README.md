# Tally — Android app

Nutrition, workouts and friends. Web code wrapped as a native Android app with [Capacitor](https://capacitorjs.com), backed by [Supabase](https://supabase.com).

## How the food data works (mixed approach)

| Data | Where it lives |
|---|---|
| Generic foods: Health Canada CNF 2015 (5,690) + USDA SR28 (8,789), 19 nutrients each | Bundled in the app (`public/data`, ~0.75 MB compressed) — instant and offline |
| Packaged products (barcodes) | Looked up live on Open Food Facts; every product you scan is cached on the phone |
| Products not found | Photo of the Nutrition Facts label → Claude reads it → saved to your foods, linked to the barcode |

## Folder map

```
supabase/migrations/   Database schema + row-level security (run once in Supabase)
supabase/functions/    send-invite (friend invites by email), claude (AI proxy, keeps your API key secret)
supabase/tests/        Local security tests (28 checks)
tests/live.mjs         Live tests against your project with throwaway accounts (`node tests/live.mjs`)
src/                   App code
public/data/           Bundled food databases
android/               Native Android project (generated by Capacitor)
.github/workflows/     Builds an installable APK on GitHub automatically
```

## One-time setup

### 1. Supabase project
1. Create a project at supabase.com (free tier is fine).
2. **SQL Editor →** paste the *contents* of each file in `supabase/migrations/`, in name order, and Run each one:
   `20261031000000_init.sql` (tables + security), then `20261031010000_delete_account.sql` (in-app account deletion).
3. **Authentication → Sign In / Providers → Email:** keep Email enabled.
4. **Authentication → Emails → Magic Link** template — make sure it shows the 6-digit code, e.g.
   `Your Tally sign-in code is {{ .Token }}`
5. **Authentication → Emails → Invite user** template, e.g.
   `{{ .Data.invited_by }} invited you to Tally. Install the app and sign in with this email address — you'll already be friends.`
6. Supabase's built-in email sender only allows a few emails per hour. Before inviting many friends, connect a real sender under **Authentication → Emails → SMTP Settings** (Resend, Postmark and SendGrid all have free tiers).

### 2. Server functions
With the [Supabase CLI](https://supabase.com/docs/guides/cli):
```
supabase login
supabase link --project-ref YOUR-PROJECT-REF
supabase functions deploy send-invite
supabase functions deploy claude
supabase secrets set ANTHROPIC_API_KEY=sk-ant-...      # for "Describe it" and label reading
```
Get an Anthropic API key at console.anthropic.com. Claude use is billed per request (fractions of a cent per label); `CLAUDE_DAILY_LIMIT` (default 60/user/day) caps it.

### 3. Build the APK — pick one
**A. GitHub (no Android Studio needed):** push this folder to a GitHub repo, add repository secrets `SUPABASE_URL` and `SUPABASE_ANON_KEY` (Settings → Secrets and variables → Actions). Every push builds `tally-debug-apk` under the workflow run's **Artifacts** — download it on your phone and install (allow "install unknown apps").

**B. Android Studio:** `.env` already points at your project (create it from `.env.example` if missing), then
```
npm install
npm run android      # builds, syncs and opens Android Studio → press Run
```

## Security model (enforced in the database, not the app)
- Your diary, foods, routines and workouts (`user_docs`) are readable only by you.
- Friends are made only through an email invite that the invitee's verified email matches.
- Friends can see: your name/emoji, achievements you mark "friends", and the stats you choose to share. Never your diary.
- Chats are visible only to their members; you can only start chats and challenges with friends.
- Unfriending removes access immediately.

Run the security tests locally (needs PostgreSQL 15+):
```
createdb tally_test
psql -d tally_test -f supabase/tests/supabase_shim.sql -f supabase/migrations/20261031000000_init.sql -f supabase/tests/rls_test.sql
```
